<h3>以可视化方式构建 AI Agents</h3>

![SynapseFlow](https://github.com/SynapseFlowAI/SynapseFlow/blob/main/images/SynapseFlow_agentflow.gif?raw=true)

## ⚡ 快速入门

1. 安装 SynapseFlow
    ```bash
    npm install -g SynapseFlow
    ```
2. 启动 SynapseFlow

    ```bash
    npx SynapseFlow start
    ```

3. 打开[http://localhost:3000](http://localhost:3000)

## 🌱 环境变量

SynapseFlow 支持不同的环境变量来配置您的实例。您可以在`packages/server`文件夹中的`.env`文件中指定以下变量。阅读[更多](https://docs.SynapseFlowai.com/environment-variables)

您还可以在使用`npx`时指定环境变量。例如：

```
npx SynapseFlow start --PORT=3000 --DEBUG=true
```
